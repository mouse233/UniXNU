# Redmi Note 14 Pro+ 5G（amethyst）

amethyst 是搭载 SM7635 的 Redmi Note 14 Pro+ 5G。下面的移植是独立的社区项目，UniXNU 组织不维护它。目标是 iPhone X（iPhone10,3）用户态。

| 仓库 | 维护者 |
| --- | --- |
| [UniXNU-amethyst](https://github.com/andr0d1v/UniXNU-amethyst) | [andr0d1v](https://github.com/andr0d1v) |

## 当前状态

仓库已提供板级配置、ADT 生成器、负载准备和内核构建流程。移植等待可用的目标 UEFI 实现，随后才能验证菜单、DarwinBoot、内核入口和根卷。

固件参考为 BluedMC-Amethyst/uefi-amethyst 的 `amethyst` 分支。所需 bootstrap 和输入见设备 README。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
